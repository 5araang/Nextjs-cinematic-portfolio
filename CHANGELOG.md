## [1.0.0] - 2026-07-29

### 🚀 Added
- **Next.js 16 & React 19 Engine**: Built on Next.js App Router architecture.
- **Scroll-Driven Video Scrubbing**: Frame-accurate canvas video scrubbing synced to user scrolling speeds.
- **GSAP 3 Animation System**: 120fps smooth scroll-triggered animations and magnetic cursor interactions.
- **Collapsible Admin Dashboard**: Administrative CMS sidebar with desktop collapse state (`localStorage` persistence) and mobile blur drawer.
- **Native Privacy Analytics**: Built-in tracking engine for total visits, today's visits, page views, country/city geolocation, device detection, CTA link clicks, and search queries.
- **Markdown Blogging Engine**: Full markdown blog post editor with admin-repliable threaded user comments and dynamic tagging.
- **Resend Contact Routing**: Contact form inquiries integrated directly with Resend email API.
- **Coming Soon Mode**: Configurable launch protection splash screen with passcode bypass.
- **AI Agent Context (`llms.txt` & `llms-full.txt`)**: Machine-readable information feeds optimized for ChatGPT, Gemini, Claude, and Perplexity.
- **Schema.org Structured Data**: JSON-LD schemas (`Person`, `WebSite`, `SoftwareSourceCode`, `SiteNavigationElement`, `FAQPage`, `HowTo`, `SoftwareApplication`).
- **Dynamic Sitemaps & Robots**: Automated `sitemap.xml` and `robots.txt` generation.
